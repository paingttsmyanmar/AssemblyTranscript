# 🎬 TranscriptTools

AI Video and Audio Transcript Web App powered by AssemblyAI.

## Features

✅ Video to Text  
✅ Audio to Text  
✅ MP4 / MP3 / WAV / M4A Support  
✅ Multi Language Detection  
✅ User Own AssemblyAI API Key  
✅ Download Transcript TXT  

## How to Use

1. Get your AssemblyAI API Key
2. Enter your API Key
3. Upload Video or Audio
4. Generate Transcript

Built with:
- Streamlit
- AssemblyAI
